## Recommended control point

Prefer original reuse for this group's primary imagery. Courtline 117 and Flow Skort 154 have usable existing colour coverage for a visual canary, subject to the separate catalogue, backup, selector and cart gates. Court Dress 36 needs explicit acceptance of the navy crop/hem representation before a claim of a coherent four-colour pack.

Do not use generation to manufacture absent rear views, internal shorts, pockets, support cups, fabric weave or garment construction. Existing source crops can demonstrate visible details at their actual available resolution; they do not create new evidence. If the desired final gallery requires additional views, locate a matching supplier/existing reference first or explicitly retain the smaller supported gallery.

For all nine products, shade approval, exact product/colour/variation mapping, commerce matrix checks, responsive rendering and live readback remain separate pending gates. This review changes no catalogue record, image, stock value, price, variation ID or production switch.
